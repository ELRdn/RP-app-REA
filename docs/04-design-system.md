# デザインシステム分析

ZetaとSynClubは、同じ「AIキャラChat」でも**トークンの作り方**がまったく違います。ZetaはTailwindのユーティリティに**意味のある名前**（`gray-main`, `primary-400`, `rounded-6`）を付け、SynClubは**Element Plusの変数＋remスケーリング**で組んでいます。この章では、実測値と本番CSSから両社のトークンを復元し、比較します。

> 実測の生データ：`evidence/tokens/zeta-observed.json` / `evidence/tokens/synclub-observed.json`
> キュレーション版：`data/tokens.json`
> CSS変数：`analysis/design-tokens.css`

---

## 1. トークンアーキテクチャ

| | Zeta | SynClub |
|---|---|---|
| 方式 | Tailwind CSS v4（`@layer` / `--tw-*` / `lab()` 出力） | 手書きBEM + Element Plus |
| 色 | **ハードコードされたhex**（`#6728FF`） | hex + `rgba()`、一部 `--el-*` |
|  spacing | `p-4` `gap-2` などのユーティリティ | `rem` 固定値（`1.25rem` 等） |
| タイポ | セマンティッククラス（`title16`, `body14`） | `font-size:1.125rem` を直接 |
| 角丸 | `rounded-6/8/10/12/16` | `border-radius:2rem` 等 |
| テーマ | クラス差し替え（`Halloween*`） | ライト固定、Element Plusの既定色が残存 |
| ルート | `html { font-size:16px }` 固定 | `html { font-size:3.8647vw }`（390pxで15.07px） |

Zetaの方が**トークンの語彙が整理**されています。`gray-main`（背景）`gray-sub1`（カード）`gray-sub2`（ホバー）`gray-sub3`（ボーダー）という階層は、ダークUIで破綻しないための実践的な命名です。SynClubはElement Plusのデフォルト（`--el-color-primary: #409EFF`）を残したままコーラルで上書きしており、**トークンの一貫性はZetaの勝ち**です。

## 2. カラー

### 2.1 Zeta

| トークン | 値 | 用途 | 白背景とのコントラスト |
|---|---|---|---|
| `gray-main` | `#151516` | 画面背景 | — |
| `gray-sub1` | `#212122` | カード、モーダル | — |
| `gray-sub2` | `#333333` | ホバー、チップ | — |
| `gray-sub3` | `#525457` | 強ボーダー | — |
| `primary-400` | `#6728FF` | 主ボタン、アクティブ | 白文字 6.32:1（AA） |
| `primary-500` | `#5220CC` | 押下 | — |
| `primary-300` | `#7C67FF` | リンク、グラデ | — |
| `primary-200` | `#A799FF` | 薄いアクセント | — |
| `text` | `#FFFFFF` | 本文 | 18.25:1（AAA） |
| `text-secondary` | `rgba(255,255,255,.7)` → `#B9B9B9` | 補助 | 9.30:1（AAA） |
| `text-tertiary` | `rgba(255,255,255,.5)` → `#8A8A8B` | タグ、注釈 | 5.29:1（AA） |
| `orange` | `#FF8A3D` | ハロウィン、警告 | — |
| `lime` | `#D8FF66` | キャンペーン | — |
| `gold` | `#F1D99C` | Veritas | — |
| `error` | `#F04438` | エラー | — |

**観察**：白50%でも5.29:1あり、12pxのタグでもAAを満たします。ダークUIの階層設計が丁寧です。一方、紫の上に白は6.32:1で、通常テキストのAA（4.5:1）を満たします。

### 2.2 SynClub

| トークン | 値 | 用途 | コントラスト |
|---|---|---|---|
| `coral` | `#FF7870` | CTA、ロゴ、音声バブル | 白文字 2.57:1（**AA不合格**） / 黒文字 7.35:1（AA） |
| `coral-strong` | `#FF3459` | エラー、強調 | 白文字 3.6:1（大文字のみ） |
| `ink` | `#111111` | 見出し、黒ピル | 18.88:1（AAA） |
| `text` | `#333333` | 本文 | 12.63:1（AAA） |
| `text-muted` | `rgba(17,17,17,.5)` → `#888888` | 補助 | 3.54:1（**AA不合格**） |
| `page` | `#FFFFFF` | 背景 | — |
| `canvas` | `#F4F5F6` | セクション | — |
| `cream` | `#FAF0E4` | 温かい面 | — |
| `peach` | `#FEE0DE` | コーラル淡色 | — |
| `periwinkle` | `#DCE2FE` | 寒色の差し色 | — |

**観察**：コーラルは**黒文字**で使うのが正解（7.35:1）。実際、ランディングのCTAは黒ピル、`今すぐ登録` は黒文字です。しかし共有チャットの台詞バブルは**白文字 on コーラル**（2.57:1）で、長文の可読性が低い。Element Plusの `#409EFF` もCSSに残っており、トークンの統一は途上です。

### 2.3 色彩戦略の違い

- **Zeta**：背景を黒に固定し、**紫だけが動く**。紫は「触れる」「進む」「自分」の色。
- **SynClub**：白を基調に、**面の色で気分を切り替える**。コーラルは「歓迎」「話す」、クリームは「温かい」、ペリウィンクルは「静か」。

Zetaは**機能色**、SynClubは**情緒色**。同じブランドカラーでも役割が違います。

## 3. タイポグラフィ

### 3.1 Zeta — 密度の設計

`Pretendard JP Variable`。日本語の可変フォントで、ウェイトを400/500/600で運用します。

| クラス | サイズ | 太さ | 行間 | 字間 | 用途 |
|---|---|---|---|---|---|
| `title32` | 32px | 600 | 38.4px | -0.03rem | ページタイトル |
| `title24` | 24px | 600 | 28.8px | -0.0225rem | セクション |
| `title20` | 20px | 600 | 24px | -0.01125rem | モーダルタイトル |
| `title18` | 18px | 600 | 21.6px | -0.01125rem | カードタイトル |
| `title16` | 16px | 600 | 19.2px | -0.01rem | 小見出し |
| `body16` | 16px | 400 | 19.2px | -0.015rem | 本文 |
| `body14` | 14px | 400 | 16.8px | -0.013125rem | 補助 |
| `caption1` | 12px | 400 | 16px | 0 | タグ |
| `caption2` | 10px | 500 | 14px | 0 | バッジ |

**行間1.2**は日本語としてはかなり詰まっています。しかし、UIラベル・カードタイトル・タグはすべて短いので、詰めた方が「アプリらしい」密度になります。長文（プロット本文）だけは別クラスで1.5–1.7に緩めています。

### 3.2 SynClub — 比率の設計

`Poppins`（ラテン）＋日本語フォールバック。**root font-size = 3.8647vw** で、すべてのremが画面幅に比例します。

| トークン | rem | 390pxでの実測 | 用途 |
|---|---|---|---|
| display40 | 2.5 | 37.7px | ヒーロー |
| display30 | 1.875 | 28.26px | セクション見出し |
| title24 | 1.5 | 22.6px | 見出し |
| title20 | 1.25 | 18.84px | カード名 |
| title18 | 1.125 | 16.96px | タグ |
| body16 | 1 | 15.07px | 本文 |
| body14 | 0.875 | 13.19px | 補助 |
| caption12 | 0.75 | 11.3px | 注釈 |

**メリット**：どの端末でも比率が同じ。iPhone SEでもPro Maxでもレイアウトが崩れにくい。
**デメリット**：デスクトップで文字が巨大化し、固定幅のクリエイター画面と衝突する。実際、390pxの `/imageCreator/entry` は横溢れします。

### 3.3 日本語組版の違い

- Zeta：`letter-spacing` を負に振り、漢字と仮名の密度を揃える。行間1.2で「詰まった雑誌」。
- SynClub：`letter-spacing: normal`、行間normal。Poppinsのラテンと日本語フォールバックが混ざるため、**日本語のウェイトが疑似ボールド**になる。見出しは迫力が出るが、本文はやや軽い。

## 4. スペーシング / レイアウト

### 4.1 Zeta

| 項目 | 値 |
|---|---|
| 画面ガター | 16px |
| カードグリッド | 2カラム、gap 8px |
| カード | 175×233px（3:4） |
| ヘッダー | 52px |
| ボタン | 32 / 40 / 48px |
| 下部ナビ | 56–60px + safe-area |
| シェル | 最大440px |

8pxグリッドを基本に、カードだけ3:4の比率で固定。画像のアスペクトを揃えることで、フィードのリズムを作っています。

### 4.2 SynClub

| 項目 | 値 |
|---|---|
| 上部バー | 48px |
| ガター | 15.07px（1rem） |
| カード | フル幅、画像390×420 |

モバイルは**1カラムの大きなカード**、デスクトップは**4カラムの小さなカード**。同じ `card-item` でも情報密度がまったく違います。

## 5. コンポーネント解剖

### 5.1 ボタン

| | Zeta | SynClub |
|---|---|---|
| 主 | 紫 `#6728FF`、角丸6px、高さ32/40/48、白文字 | 黒 `#111` ピル、白文字、高さ48–56 |
| 副 | 白5%のゴースト、白ボーダー | 白/黒5%のゴースト、黒文字 |
| 遷移 | 150ms | 200–300ms |
| アイコン | 16px SVG | 20–24px Iconify |

Zetaは**小さく角ばった**ボタン、SynClubは**大きく丸い**ピル。Zetaの方が情報密度を優先し、SynClubはタップの快感を優先しています。

### 5.2 カード

**Zetaのプロットカード**

```
[画像 3:4、上角丸12px]
  ↳ 左上: チャット数バッジ（黒60%、角丸6px、10px）
  ↳ 右下: いいね
[タイトル 16px/600、2行]
[タグ 12px/50%白、横スクロール]
[作者 12px/50%]
```

**SynClubのキャラカード**

```
[画像 390×420、角丸18.8px]
  ↳ 左下: 名前 20.7px/600 + 年齢
  ↳ 下: タグ（白10%ピル、16.96px）
[説明カード（黒6%、角丸18.8px、15px/1.37）]
```

Zetaは**画像の上に情報を重ねる**、SynClubは**画像の下に説明を置く**。前者は一覧性、後者は読み物性。

### 5.3 チップ / タブ

- Zeta：小さなピル（角丸9999、12px、白5%）。ランキングのジャンル、検索のタグ。
- SynClub：**巨大な文字タブ**（18.8px/600、角丸9.4px、アクティブは黒5%背景）。手描き風の下線。

SynClubのタブは「文字が主役」。Zetaのタブは「状態の表示」。同じタブでも役割が違います。

### 5.4 入力

- Zeta：角丸6pxのフィールド、紫のフォーカスリング、プレースホルダ白30%。
- SynClub：Element Plusの `el-input`、角丸4px、フォーカスでコーラル。

### 5.5 モーダル

- Zeta：**ボトムシート**。下からせり上がり、上角丸16px、背景dim 60%。ログイン、通報、設定。
- SynClub：**中央モーダル**。白、角丸16–30px、QRコード、`親愛なるユーザー 🧩`。

ZetaはモバイルOSの作法、SynClubはWebの作法。Zetaの方が「アプリ感」が強い。

### 5.6 チャットバブル

| | Zeta | SynClub |
|---|---|---|
| 角丸 | 16px + 尻尾 | 16–20px |
| ユーザー | 紫グラデ、白文字 | 入力バーのみ（共有） |
| キャラ | `#2A2A2C`、白文字 | コーラル、白文字（2.57:1） |
| 名前 | 12px/50%白 | バブル外の黒チップ |
| ナレーション | `≡` + 白70% | 黒バブル |
| 音声 | なし | `▶ 14"` |

SynClubのコーラルバブルは**白文字のコントラストが低い**。黒文字にすれば7.35:1になるので、簡単に直せます。

### 5.7 空状態 / 404

- Zeta：紫のアウトラインアイコン＋日本語コピー＋グレーボタン。ミニマル。
- SynClub：キャラ画像のモザイクで `404`。ブランド資産を使った遊び。

## 6. モーション

| | Zeta | SynClub |
|---|---|---|
| 基本 | 150ms color、200–250ms modal | 200ms fade、300ms transform |
| イージング | `cubic-bezier(0.4,0,0.2,1)` | `cubic-bezier(.645,.045,.355,1)` / `.23,1,.32,1` |
| カルーセル | 自動、`2/7` | マーキー（LP） |
| 季節 | `ShakeStage`（揺れ） | タブ下線の手描き質感 |
| フィードバック | ボタン色、トースト | モーダル、トースト |

Zetaは**短く・静か**、SynClubは**やや長く・弾む**。Element Plusの標準トランジションがそのまま出ているのがSynClubの特徴です。

## 7. アイコン / イラスト

- **Zeta**：下部タブは**PNG画像**（`chat-on.png`, `create-off.png` など）。ハロウィン版はカボチャのPNG。SVGはUI操作用（戻る、検索、送信、`*`）。マスコットは3D/グラデーションの blob。
- **SynClub**：IconifyのSVG（`iconify--svg`）、丸背景の白アイコン。ロゴはグラデーションSVG（`#FF9472` → `#FF7870`）。3Dマスコット、手描き線、ドット。

Zetaは**画像アセット**で温かみを出し、SynClubは**SVG＋手描き**で軽さを出しています。

---

## 8. テーマ / 季節

Zetaのハロウィンは、単なる色替えではなく**コンポーネント差し替え**です。

- `HalloweenNavigationBar.tsx`：ナビ全体
- `HalloweenTabBarIcon.tsx`：タブアイコン
- `HalloweenHomeDecoration.tsx`：背景装飾
- `HalloweenStyles`：追加CSS
- `VeritasIntroPage.tsx`：ブランドコラボ用のイントロ

これにより、通常UIを壊さずに**季節ごとの空気**を注入できます。SynClubはWebにダークモードがなく、テーマ切替の仕組みは確認できませんでした（`desktop_synclub_dark_feed.png` でもライトのまま）。

## 9. アクセシビリティ監査

Lighthouse（Chrome, モバイルエミュレーションなし）の実測：

| ページ | Accessibility | Best Practices | SEO | 主な失敗 |
|---|---|---|---|---|
| Zeta ホーム | **0.76** | 0.83 | 1.00 | button-name, link-name, listitem, meta-viewport（maximum-scale=1）, target-size |
| SynClub キャラフィード | **0.90** | 1.00 | 1.00 | color-contrast |
| SynClub ランディング | **1.00** | 1.00 | 1.00 | なし |

レポート：`evidence/lighthouse/`。Zetaの0.76は、アイコンのみボタンとリンク名の欠落、`maximum-scale=1`（ズーム禁止）、タップ領域の小ささが主因です。SynClubの0.90は、ミュートテキストのコントラスト（`rgba(17,17,17,.5)`）によるものです。

| 項目 | Zeta | SynClub |
|---|---|---|
| コントラスト（本文） | 18.25:1 ✅ | 12.63:1 ✅ |
| コントラスト（補助） | 5.29:1 ✅ | 3.54:1 ❌ |
| コントラスト（CTA） | 6.32:1 ✅ | 黒文字 7.35:1 ✅ / 白文字 2.57:1 ❌ |
| フォーカス | 紫リング ✅ | ほぼなし ❌ |
| セマンティクス | リンク/ボタン ✅ | タブ/カードがdiv ❌ |
| aria-label | 英語のまま ⚠️ | 少ない ⚠️ |
| 文字サイズ | 10pxのキャプション ⚠️ | 11.3pxの注釈 ⚠️ |
| キーボード | タブ移動可 ✅ | カテゴリ選択不可 ❌ |

**Zetaの改善点**：`aria-label` の日本語化（`戻る` `送信` `アスタリスクを挿入`）、10pxキャプションの12px化、広告の閉じるボタンのラベル。
**SynClubの改善点**：タブを `<button role="tab">` に、カードを `<a href>` に、フォーカスリングの追加、コーラル上の白文字を黒に、`rgba(17,17,17,.5)` を `#6B6B6B` 程度に。
